Real History for Kids

Companion library to the Empyrean Real History mod for Civilization V. Written for ages 8–12. Honest, sourced, video-embedded.

How to use this

Install the Civ V mod. When something new is encountered in game, a popup appears with a short lecture and a button that opens the full page here — video, deeper reading, and sources.

Grown-ups can also give any page's URL to a kid's AI assistant (Gemini, ChatGPT, Claude, Copilot) and ask it to quiz the kid on that page. The library is plain markdown — every major AI can read it.
